# Movie Rating Prediction

## Project Overview

This project predicts the rating of a movie using machine learning techniques and movie-related features.

## Dataset

The project uses the IMDb India Movies dataset.

## Features Used

* Year
* Duration
* Votes
* Genre
* Director
* Actor 1
* Actor 2
* Actor 3

## Machine Learning Model

* Random Forest Regressor
* Gradient Boosting Regressor

## Steps Performed

1. Data Cleaning
2. Exploratory Data Analysis (EDA)
3. Feature Selection
4. Train-Test Split
5. Data Preprocessing
6. Model Training
7. Model Evaluation
8. Actual vs Predicted Rating Analysis

## Model Performance

Random Forest Regressor achieved an R² Score of approximately **0.37**.

## Project Files

* `Movie_Rating_Prediction.ipynb` — Complete project notebook
* `movie_rating_model.pkl` — Saved trained model
